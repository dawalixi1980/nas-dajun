# 07 · construction-wiki（施工 Wiki）

## 职责

把归档整理成**施工交付物**：按天递进的结构层 + 施工日志 + 单价台账。

## 输入输出

```
<某个目录>/
├── 群聊归档/                  ← 输入（整理器产出，可迁移）
│   └── <群名>_2026-11-07/{消息,图片}/
└── 项目信息/                  ← 输出（与群聊归档同级）
    └── <项目名>/              ← 群名 = 项目名
        ├── raw/               原始副本（只追加）
    │   ├── 消息/2026-11-08.jsonl
    │   └── 图片/2026-11-08/
    ├── 结构/                  人可读结构
    │   ├── index.md
    │   └── 2026.11月/
    │       ├── index.md
    │       └── 08/
    │           ├── index.md
    │           ├── 聊天记录.md
    │           ├── 图片/
    │           └── events.jsonl
    └── 输出/
        └── 施工日志与单价台账.xlsx
```

**插件只认名字叫「群聊归档」的目录**，自动发现并在同级生成「项目信息」，
所以整个文件夹可以随意迁移，不需要改配置。

## 每日自动整理

面板设定时间（默认 22:00），写入系统定时任务：

```
每天 22:00 → 扫描「群聊归档」→ 重组「项目信息」→ 生成 Excel
关掉 DSH 也会执行
```

## 施工日志（12 列）

项目名称 · 日期 · 拍摄时间 · 天气 · 地点 · 建设单位 · 施工单位 · 监理单位 · 分项工程 · 部位 · 事项 · 图片

## 单价台账（9 列）

日期 · 项目名称 · 事项 · 单位 · 数量 · 单价 · 金额 · 依据原文 · 备注

规则：
- 只认原文明确写法：`480元/方`、`单价 480`、`480元每方`
- 有数量没单价 → 数量照记，备注「原文未提及单价」
- 两者都有 → 自动算金额
- **抽不到就留空，绝不编造**

## 规则提取（不花 token）

| 字段 | 规则 |
| --- | --- |
| 天气 | 匹配 晴/多云/阴/小雨/中雨/大雨/阵雨/雪/雾/大风 |
| 地点 | 匹配 `K1+200`、`3号路`、`一标段` |
| 单位 | 匹配 `(建设\|施工\|监理)单位[：:]\s*(\S{2,20})` |
| 分项 | 关键词归类（见下表） |
| 单价 | `(\d+(\.\d+)?)\s*元\s*/\s*(方\|m³\|吨\|平方\|米\|个\|根)` |
| 数量 | 先挖掉「N元/单位」，再匹配 `(\d+(\.\d+)?)\s*(方\|吨\|个…)` |

### 分项体系（道路工程）

```
路基   ← 清表、土方、填筑、压实、路床、边坡、换填、软基
路面   ← 底基层、基层、面层、沥青、水稳、碎石垫层
挡土墙 ← 挡墙、墙身、泄水孔、墙背回填
桥涵   ← 桩基、承台、台身、梁板、盖梁、桥面、涵洞、墩柱
排渠   ← 沟槽、管道、检查井、雨水管、污水管、箱涵、盖板
```

## 实测样例

```
"今天晴，K1+200 路基填筑 1200方，单价18元/方"
  → 分项=路基 天气=晴 地点=K1+200 单价=18 数量=1200 金额=21600

"C30混凝土 480元/方，今天浇了 35方"
  → 单价=480 数量=35 金额=16800

"监理单位：中建监理 施工单位：三建 建设单位：城投"
  → 三个单位全部抽出
```

## 去重

`dsh-qq-access` 换号会重复归档同一条消息（去重键含 selfId）。
`build-structure.mjs` 按 `messageId` 去重，实测清理了 12 条重复。

## 技能更新机制

插件只监听仓库的 `dajunskill/` 目录：

1. 「检查更新」→ GitHub API `commits?path=dajunskill`
2. 「更新技能」→ 从 raw.githubusercontent.com 拉取 `SKILL.md`
3. 写入 `~/.dsh/skills/construction-wiki/`
4. 规则变化后需重建结构层

**不需要 git**，Windows/macOS 一致。
