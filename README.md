# nas-dajun

个人技术栈合集：QQ 机器人接入、群聊归档、结构化工程资料生成。

全部基于 **DeepSeek Harness (DSH)** 的插件体系，跑在桌面端。

## 目录

| 目录 | 说明 | 平台 |
| --- | --- | --- |
| `1.napcat技术栈` | NapCat 协议栈方案 | — |
| `2.qq管家技术栈` | QQ 管家主线（macOS 起家，保持原样） | macOS |
| `qq 管家技术栈 win` | QQ 管家 Windows 版（独立维护） | Windows |

> 两个 qq 管家目录**各自独立、互不覆盖**：macOS 主线不动，Windows 侧改动只进 `qq 管家技术栈 win`。

## QQ 管家是什么

两个自研插件，合起来是一套「群聊 → 归档 → 工程资料」的流水线：

| 插件 | 包名 | 职责 |
| --- | --- | --- |
| QQ 机器人 | `dsh-qqbot-multi` | 接入 QQ 官方机器人；收发消息、会话管理、群聊归档、策略裁决、桥接生成 |
| QQ 管家 | `dsh-qq-butler` | Web 面板：机器人策略、归档目录、桥接开关、状态查看、手动整理 |

数据全部落在 `~/.dsh-qqbot/`，与 DSH 自身的会话目录互不干扰。

能力概览：

- 多个 QQ 官方机器人同时在线，各自独立选模型、独立工作目录
- 每个机器人三种策略：静默收集 / 不收集 / 活跃
- 群聊全量归档（文字 + 图片 + 文件），按「机器人 / 群 / 日期」组织，同时生成可读 txt
- **一个群一个文件夹**，群目录可用 `/rename` 改名，机器人改名时归档目录自动跟着改
- 桥接生成施工 Wiki 式结构层：`年.月/日/聊天记录.md + events.jsonl + 图片/`
- 自动产出 `施工日志.xlsx` 与 `单价台账.xlsx`
- 群内命令：`/todo` `/day` `/rename` `/groups` `/github` `/skill`
- 面板一键从本仓库更新插件代码

## 快速开始

1. 在 DSH 里安装 `plugins/` 下的两个插件（见 `docs/09-更新机制.md`）
2. 面板 → 设置 → QQ 管家 → 填归档目录 → 勾选桥接机器人
3. 机器人进群后发一条消息，归档自动建立
4. 群里 `/rename 项目名` 给群目录起名

## 更新

两种方式，效果相同：

- **面板**：QQ 管家 →「检查更新」
- **群里或私聊**：发 `/update`

更新内容是 `plugins/` 下的插件源码，拉取后覆盖到本机对应位置，重启桌面端生效。
