# dsh-construction-wiki

DSH 插件：把 QQ 群聊归档整理成施工 Wiki。

## 做什么

```
QQ 群消息（原始流水）
  → 按项目 / 按天 的结构层（可读、可检索）
  → 施工日志 Excel + 单价台账 Excel
```

**全程规则处理，不调用大模型，不消耗 token。**

## 三层结构（每个项目自成一套）

```
<项目根>/
└── <项目名>/                  ← 群名 = 项目名
    ├── raw/                   原始归档（只追加）
    ├── 结构/                  按 年.月/日 递进的人可读结构
    │   ├── index.md
    │   └── 2026.11月/08/
    │       ├── index.md
    │       ├── 聊天记录.md
    │       ├── 图片/
    │       └── events.jsonl
    └── 输出/
        └── 施工日志与单价台账.xlsx
```

## 施工日志字段

项目名称 · 日期 · 拍摄时间 · 天气 · 地点 · 建设单位 · 施工单位 · 监理单位 · 分项工程 · 部位 · 事项 · 图片

## 单价台账

日期 · 项目名称 · 事项 · 单位 · 数量 · 单价 · 金额 · 依据原文 · 备注

规则：
- 只认原文明确写法（`480元/方`、`单价 480`）
- 有数量没单价 → 数量照记，备注「原文未提及单价」
- 两者都有 → 自动算金额

## 分项体系（道路工程）

```
路基   ← 清表、土方、填筑、压实、路床、边坡、换填、软基
路面   ← 底基层、基层、面层、沥青、水稳、碎石垫层
挡土墙 ← 挡墙、墙身、泄水孔、墙背回填
桥涵   ← 桩基、承台、台身、梁板、盖梁、桥面、涵洞、墩柱
排渠   ← 沟槽、管道、检查井、雨水管、污水管、箱涵、盖板
```

## 安装

```bash
pnpm add file:/path/to/dsh-construction-wiki
```

然后在 profile 的 `package.json` 里把 `dsh-construction-wiki` 加进 `dsh.profile.bundles`。

## 工具

| 工具 | 作用 |
| --- | --- |
| `wiki_build` | 生成结构层 + Excel |
| `wiki_status` | 根目录、项目列表、版本 |
| `wiki_check_update` | 检查本仓库是否有新提交 |

## 数据来源

依赖 `dsh-qq-access` 的归档：`~/.dsh-qq-access/data/messages/*.jsonl`
