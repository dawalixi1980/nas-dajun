# 施工 Wiki

把 QQ 群聊归档整理成**可查、可交付**的施工资料。

## 输入输出

```
<某个目录>/
├── 群聊归档/                       输入（整理器产出，可迁移）
│   └── <群名>_2026-11-07/
│       ├── 消息/2026-11-08.jsonl
│       └── 图片/2026-11-08/
└── 项目信息/                       输出（与群聊归档同级）
    └── <群名>/
        ├── raw/        原始副本（只追加）
        ├── 结构/       按 年.月/日 递进
        └── 输出/       施工日志与单价台账.xlsx
```

**群名 = 项目名。** 只要目录名叫「群聊归档」，插件会自动发现它，
并在**同级**生成「项目信息」。所以迁移文件夹后无需改配置。

## 结构层

```
项目信息/<项目>/
├── 结构/
│   ├── index.md                    项目索引 → 月份
│   └── 2026.11月/
│       ├── index.md                月索引 → 日期
│       └── 08/
│           ├── index.md            当日概览
│           ├── 聊天记录.md          当天全部消息
│           ├── 图片/                硬链接，不占额外空间
│           └── events.jsonl         结构化事件（台账数据源）
├── raw/                            原始 JSONL 与图片
└── 输出/                             Excel
```

## 施工日志（12 列）

项目名称 · 日期 · 拍摄时间 · 天气 · 地点 · 建设单位 · 施工单位 · 监理单位 · 分项工程 · 部位 · 事项 · 图片

## 单价台账（9 列）

日期 · 项目名称 · 事项 · 单位 · 数量 · 单价 · 金额 · 依据原文 · 备注

- 只认原文明确写法：`480元/方`、`单价 480`、`480元每方`
- 有数量没单价 → 数量照记，备注「原文未提及单价」
- 两者都有 → 自动算金额
- **抽不到就留空，绝不编造**

## 规则提取（不花 token）

| 字段 | 规则 |
| --- | --- |
| 天气 | 匹配 晴/多云/阴/小雨/中雨/大雨/阵雨/雪/雾/大风 |
| 地点 | 匹配 `K1+200`、`3号路`、`一标段` |
| 单位 | 匹配 `(建设\|施工\|监理)单位[：:]` 后跟名称 |
| 分项 | 关键词归类（见下表） |
| 单价 | `(\d+(\.\d+)?)\s*元\s*/\s*(方\|m³\|吨\|平方\|米\|个\|根)` |
| 数量 | 先挖掉「N元/单位」，再匹配 `(\d+(\.\d+)?)\s*(方\|吨\|个…)` |

### 分项体系（道路工程）

```
路基   ← 清表、土方、填筑、压实、路床、边坡、换填、软基
路面   ← 底基层、基层、面层、沥青、水稳、碎石垫层
挡土墙 ← 挡墙、墙身、泄水孔、墙背回填
桥涵   ← 桩基、承台、台身、梁板、盖梁、桥面、涵洞、墩柱
排渠   ← 沟槽、管道、检查井、雨水管、污水管、箱涵、盖板
```

## 命令

```
wiki_build            # 立即执行一次（结构层 + Excel）
wiki_status           # 根目录、项目列表、版本
wiki_check_update     # 查仓库 dajunskill/ 是否有新提交
wiki_update_skill     # 从仓库拉取最新技能定义
wiki_schedule         # 设置每日自动执行时间
```

## 每日自动整理

在面板里设定时间（例如 22:00），插件会写系统定时任务：

```
每天 22:00 → 扫描「群聊归档」→ 重组「项目信息」→ 生成 Excel
关掉 DSH 也会执行
```

Windows 上用计划任务调用 `tools/daily.sh`（PowerShell 脚本见仓库 `nas-qq/scripts/windows/`）。

## 去重

整理器的去重键包含 `selfId`，换号后会把历史重捞一遍。
本插件按 `messageId` 去重（实测清理过 12 条重复）。

## 兜底

整理器对「曾被隐藏的群」会跳过写入但照样推进游标，导致归档缺消息。
本插件检测到某项目无消息时，会从 `~/.dsh-qq-access/data/messages` 按
`peerId` 补齐，避免数据缺口。
