# 03 QQ 管家面板 dsh-qq-butler

纯前端插件，注册到「设置 → QQ 管家」。数据全部来自机器人插件的 `/archive2` 接口。

## 面板结构（从上到下）

| 区块 | 内容 |
| --- | --- |
| 标题 | 说明 + 立即整理 / 刷新 |
| 归档目录 | 路径输入框 + 保存 + 选择文件夹 + 浏览文件夹 + 主目录 |
| 桥接归档 | 每个机器人一个开关：是否生成工程信息 |
| 工程信息 | 桥接输出路径、每个群的两个 Excel 是否已生成 |
| 新机器人默认策略 | 三选一 |
| 机器人列表 | 每个机器人一条策略选择 + 已归档群数 |
| 命令库 | 群聊命令 / 私聊命令 两栏，数据来自接口 |

## 接口约定

`POST /archive2`，body 带 `action`：

| action | 参数 | 作用 |
| --- | --- | --- |
| `organize` | — | 立即整理 + 桥接 |
| `setRoot` | `root` | 改归档根目录 |
| `setMode` | `bot`, `mode` | 设置某机器人策略 |
| `setDefaultMode` | `mode` | 新机器人默认策略 |
| `setBridge` | `bot`, `enabled` | 开关桥接 |
| `commands` | — | 命令库 |
| `listDir` | `path` | 列目录（5 秒超时保护） |
| `rename` | `group`, `name` | 改群文件夹名 |

`GET /archive2` 返回快照：`root / autoOrganize / bridgeBots / bridged / modes / groups`。

## 目录选择器的三种实现

1. **选择文件夹…** → `POST /qqbot/bots/pick-dir`（系统原生，10 分钟超时）**推荐**
2. **浏览文件夹** → 应用内列表（`listDir`），不弹窗，适合远程
3. **直接输入路径** → 保存

> 踩坑：应用内早期版本用 `readdirSync` 列目录，遇到休眠盘会阻塞整个进程。
> 现已改为异步 + 5 秒超时，超时返回错误而不是卡死。

## 客户端依赖注入

```js
const inject = ["slots", "remote", "remote.directoryPicker"];
```

必须精确到服务名，只写 `remote` 会在访问 `remote.directoryPicker` 时报错。

## 同源校验与本机别名

面板的写接口（扫码、保存配置、改名等）会校验请求来源，防止跨站调用：

```js
origin === undefined            → 放行（同源 GET 通常没有 Origin）
origin.host === req.headers.host → 放行
双方都是回环地址且端口相同       → 放行（127.0.0.1 / localhost / ::1）
其余                             → 403
```

第三条是为本机访问准备的：用 `http://localhost:端口` 打开面板、而接口地址写成
`http://127.0.0.1:端口` 时，浏览器会把它们当成不同来源。如果不做这个兼容，
扫码等 POST 请求会静默 403，前端拿不到 `phase`，界面会一直停在
「正在向微信申请二维码…」。

外部来源仍按 Host 严格比对，安全性不变。
