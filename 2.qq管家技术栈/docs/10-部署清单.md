# 10 部署清单

从零把这套技术栈装到一台新机器上。

## 前置

- macOS（Windows 差异见 08）
- 已安装 DeepSeek Harness 桌面端
- 能访问 GitHub 仓库（SSH key 或 HTTPS 凭证）

## 1. 克隆仓库

```bash
git clone git@github-nas-dajun:dawalixi1980/nas-dajun.git
cd nas-dajun/2.qq管家技术栈
```

## 2. 安装两个插件

插件目录必须在 DSH profile 里可加载：

```bash
# 机器人插件（源码 → 任意目录，然后 link 进 profile）
ln -s <仓库>/plugins/dsh-qqbot-multi ~/.dsh/profiles/desktop/node_modules/dsh-qqbot-multi

# 面板插件
ln -s <仓库>/plugins/dsh-qq-butler  ~/.dsh/profiles/desktop/node_modules/dsh-qq-butler
```

然后在 DSH 里：

```
插件管理 → 安装 bundle → 选这两个包 → 启用
```

或者用面板「设置 → 插件」逐个启用。

## 3. 配置 profile

把 `config/profile-cordis.patch.template.yml` 的内容合并进：

```
~/.dsh/profiles/desktop/cordis.patch.yml
```

**必须改的地方：**

| 字段 | 说明 |
| --- | --- |
| `bots[].appId` / `appSecret` | 从 QQ 开放平台拿 |
| `cwd` | 机器人的工作目录 |
| `sendFile.extraRoots` | 允许发文件的额外路径 |
| `requireMention` | 设 `true`，实际由 groupArchive 接管 |

## 4. 机器人进群

1. QQ 群里把机器人加进去
2. 群设置 → 机器人 → **机器人可获取的群聊消息范围 → 获取群内全部消息**
3. 群设置 → 机器人 → **机器人主动在群聊内发言 → 开**

第 2 步决定机器人能否收到非 @ 消息，第 3 步决定能否主动推送。

## 5. 安装技能（可选）

```bash
cp -R skills/automation-task ~/.dsh/skills/
```

## 6. 验证

| 检查项 | 方法 |
| --- | --- |
| 机器人在线 | 面板 → QQ 机器人，四个机器人都显示绿点 |
| 归档生效 | 群里发一条，看 `~/.dsh-qqbot/archive/<今天>.jsonl` 有没有记录 |
| 策略生效 | 面板 → QQ 管家切策略，再发消息看是否回复 |
| 桥接生效 | 面板 →「立即生成」，看 `<机器人>工程信息/` 有没有生成 |
| Excel 生效 | 桥接目录下 `输出/施工日志.xlsx` 存在且能打开 |
| 更新生效 | 面板点「检查更新」，应显示版本号 |

## 7. 常见问题

| 现象 | 原因 |
| --- | --- |
| 收不到群消息 | 平台没开「获取群内全部消息」，或机器人不在群 |
| 收得到但不归档 | 策略是 `off`；或插件没加载新代码（重启桌面端） |
| `/todo` 没反应 | 群里没被 @ 且命令放行未生效；看 02 文档的「命令无需 @」 |
| 桥接目录不更新 | 该机器人没勾选桥接；或源目录没有数据 |
| Excel 没生成 | python/openpyxl 缺失；看日志 `wiki-bridge: Excel 生成失败` |
| 更新按钮报错 | git 凭证不可用，或 `/archive2` 接口没起（机器人插件挂了） |
