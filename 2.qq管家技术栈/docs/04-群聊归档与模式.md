# 04 群聊归档与模式

## 三种策略（按机器人，作用于它所有群）

| 策略 | 归档 | 回复 | 说明 |
| --- | --- | --- | --- |
| `collect` 静默收集 | ✅ | 仅被 @ 时 | 默认 |
| `off` 不收集 | ❌ | 仅被 @ 时 | 完全静默，只记账不存 |
| `active` 活跃 | ✅ | 每条都回 | 边聊边存 |

存储：`~/.dsh-qqbot/modes.json`

```json
{ "default": "collect", "bots": { "1905830497": "collect" } }
```

带 mtime 缓存，改完立刻生效，不用重启。

## 归档原始数据

`~/.dsh-qqbot/archive/<YYYY-MM-DD>.jsonl`，一行一条：

```json
{
  "platform": "qqbot",
  "botId": "1905830497",
  "botName": "小宝",
  "groupOpenid": "64BC7DB6…",
  "senderId": "4C29264C…",
  "senderName": "达瓦里希",
  "text": "今天路基填了 120 方",
  "mentioned": false,
  "direction": "in",              // 出站为 "out"
  "media": [
    { "contentType": "image/jpeg", "filename": "x.jpg",
      "localPath": "/Users/dada/.dsh-qqbot/media/x_123.jpg", "url": "https://…" }
  ],
  "time": "2026-11-13T02:15:03.000Z"
}
```

## 媒体

下载到 `~/.dsh-qqbot/media/`，文件名 `<hash>_<时间戳>_<短哈希>.jpg`。

**默认 24 小时清理**（`media.ttlHours`，改 0 = 永久）。清理后归档里的路径会断链，
需要长期保存的图片必须在桥接时复制走（桥接会复制到 `结构/…/图片/`）。

## 整理后的目录

```
QQ归档2/                         ← 可配置根目录
  小宝/                          ← 机器人名
    施工测试 1/                   ← 群名（/rename 定名）
      2026-11-13.jsonl           ← 当天结构化记录
      2026-11-13.txt             ← 可读聊天记录
      媒体/2026-11-13/*.jpg
```

整理是**增量**的：用 `state.json` 里每个归档文件的字节偏移做游标，只处理新增部分。

## 群名怎么来

QQ 接口不提供群名称。首次进群按 `日期_openid前8位` 建目录，之后：

- 群里发 `/rename 项目名`
- 或私聊 `/groups` 看编号 → `/rename 2 项目名`

改名会同时移动源目录与桥接目录，`state.json` 里同步更新。
