# 06 命令清单

斜杠命令由插件注册，**群聊里无需 @ 也能执行**（由 groupArchive 补标记绕过 SDK 的 @ 要求）。

| 命令 | 范围 | 说明 |
| --- | --- | --- |
| `/todo` | 群/私聊 | 开始创建定时自动化任务 |
| `/todo list` | 群/私聊 | 查看当前会话的任务（带序号） |
| `/todo list all` | 群/私聊 | 查看该机器人全部任务 |
| `/todo del 2` | 群/私聊 | 删除第 2 个任务 |

| `/day 2 昨天` | 私聊 | 指定群编号 + 日期 |

| `/rename 2 新名称` | 群/私聊 | 按编号改名 |
| `/groups` | 群/私聊 | 列出已归档的群（带编号、消息数） |

## /todo 的对话流程

```
用户：/todo
机器人：好的，要什么自动化任务？
        照着这样说就行：
        每天早上9点，在这个群发一句今日施工安全提醒
        每周一8点，发一段本周工作安排
        时间最小1分钟一次。

用户：每天早上9点，在这个群发一句今日施工安全提醒
机器人：[调用建任务工具] 已创建
```

技术要点：

- `/todo` 时按 `botId:peerId` 记一个待办，**绑定发起人 openid**
- 下一条**非命令**消息被加上 `[自动化任务]` 前缀，强制交给模型
- 只有同一发送者能消费待办 —— 否则群里的另一个机器人一句话就会把待办吃掉（踩过的坑）
- 待办 5 分钟过期

## /day 的两种模式

- 命令直接执行：插件聚合素材 → 交给模型写 120 字总结 → 发到群里
- 自然语言：模型调用 `qqbot_day_summary` 工具取素材，再自己写

素材为空时不调模型，直接回「这一天没有归档到消息」。
