## 配置要点

```yaml
- id: qqbot-multi
  config:
    cwd: "/Users/dada/项目文件"
    requireMention: true        # 保留但实际由 groupArchive 接管
    historyLimit: 3             # @ 时携带的上下文条数
    muteGroup: false
    sendFile:
      restrictPaths: true
      extraRoots: ["/Users/dada/项目文件", "/Volumes/达骏1/项目文件"]
    bots:
      - id: "1905830497"
        name: 小宝
        appId: "1905830497"
        appSecret: "…"
        access: { c2cMode: open, groupMode: open }
```

## 三个关键定制

### 1. 归档 + 策略裁决（middleware/group-archive.js）

```js
if (mode !== 'off') { …下载媒体、写 archive… }
if (命令) { 补 @ 标记; next(); return; }
if (mode === 'collect') { if (mentioned) next(); return; }
if (mode === 'active' || mentioned) next();
```

### 2. 出站归档（transport/outbound.js）

`send()` 成功后写一条 `direction: 'out'` 的记录，机器人自己的话也进记录。

### 3. 命令无需 @（middleware/group-archive.js）

SDK 的 slashCommand 在群聊强制要求 `wasMentioned`。我们对 `/` 开头的消息补一个
`mentions: [{ is_you: true }]`，绕过这道门。

## 已知限制

- QQ 官方不提供群名称，靠 `/rename` 登记
- 不提供历史消息，机器人离线期间的消息永久丢失
- 图片 CDN 链接会过期，必须接收时立即下载
- 自动化任务执行时无工具、无历史，只能生成文本
