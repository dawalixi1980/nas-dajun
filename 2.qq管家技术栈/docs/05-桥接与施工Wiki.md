# 05 桥接与施工 Wiki

把归档的群消息，按「施工资料」的结构整理成可交付的工程信息。

## 输入输出

```
输入：QQ归档2/<机器人>/<群>/<日期>.jsonl + 媒体/
输出：<机器人>工程信息/<群>/
        结构/
          index.md                 项目索引（→ 月份）
          2026.11月/
            index.md               月索引（→ 日期）
            13日/
              index.md             当日概览（消息数/图片数/分项/天气/地点）
              聊天记录.md           [HH:MM] 昵称: 内容
              events.jsonl         结构化事件（含抽取的工程要素）
              图片/                 当天图片（从媒体目录复制）
        输出/
          施工日志.xlsx
          单价台账.xlsx
          施工数据.json            中间数据（Excel 的数据源）
```

## 为什么叫「13日」而不是「13」

月份在上一级已经标了 `2026.11月`，日期仍用纯数字会出现 `2026.11月/11` 这种
月份与日期同值的歧义，所以统一加「日」。

## 规则抽取

不消耗 token，纯正则，抽不到就留空：

| 字段 | 规则 |
| --- | --- |
| 天气 | 晴/多云/阴/小雨/中雨/大雨/暴雨/阵雨/雪/雾/大风 |
| 地点 | `K1+200`、`3号路`、`一标段` |
| 单位 | `(建设\|施工\|监理)单位[：:]` 后跟名称 |
| 分项 | 路基/路面/挡土墙/桥涵/排渠 关键词归类 |
| 单价 | `(\d+)\s*元\s*/\s*(方\|吨\|平方\|米\|个…)` |
| 数量 | 先剔除「N元/单位」再匹配 |

## Excel

由 `archive2/excel.py` 生成（需要 python3 + openpyxl）。

**施工日志 12 列**：项目名称 · 日期 · 拍摄时间 · 天气 · 地点 · 建设单位 · 施工单位 ·
监理单位 · 分项工程 · 部位 · 事项 · 图片

**单价台账 9 列**：日期 · 项目名称 · 事项 · 单位 · 数量 · 单价 · 金额 · 依据原文 · 备注

规则：有单价有数量 → 算金额；有数量无单价 → 数量照记，备注「原文未提及单价」；
有单价无数量 → 只记单价。**抽不到绝不编造。**

## 改名同步

每次重建会：

1. 按当前群名生成目录，记录「应存在的目录集合」
2. 扫描输出目录，删除含 `结构/` 且不在集合里的目录（改名残留）
3. 生成失败时仍把该群目录名加入集合，避免误删

## 触发时机

- 每 `intervalMinutes`（默认 5 分钟）自动整理后
- 面板「立即生成」
- 不单独触发，挂在整理流程后面
