# 08 平台差异：macOS 与 Windows

当前实现完全在 **macOS** 上开发，部分能力依赖 macOS 特性。移植到 Windows 需要改以下几点。

## 必然要改

| 项目 | macOS | Windows |
| --- | --- | --- |
| 路径分隔符 | `/Users/dada/…` | `C:\Users\…`，代码里用 `path.join` 已兼容 |
| 默认目录 | `~/项目文件` | 需改为实际路径，配置里写死的地方要改 |
| Python 路径 | `~/.dsh/dsh-runtimes/…/python/bin/python3` | 改为 `python.exe` 或随 DSH 的运行时路径 |
| 定时任务 | `launchd`（`~/Library/LaunchAgents/com.qq.*.plist`） | 计划任务（`schtasks`）或 `Startup` 文件夹 |
| 防休眠 | `caffeinate` | `powercfg /change standby-timeout-ac 0` |
| 文件选择器 | 原生 `NSOpenPanel` | 原生对话框需重新实现 |
| 中文文件名 | NFD 规范化 | NFC，跨平台同步时要注意 |
| 文件权限 | `chmod 600` | ACL，通常可忽略 |

## 不受影响

- QQ 机器人协议（WebSocket + HTTP API）—— 平台无关
- 归档格式（JSONL）—— UTF-8，平台无关
- Excel 生成（openpyxl）—— 跨平台
- 桥接结构（目录 + Markdown）—— 只要路径用 `join` 就没事

## 迁移建议

1. 把 `~/.dsh-qqbot` 整个目录复制过去（保留 `archive/`、`state.json`）
2. 改 `config.json` 里的 `root`
3. 重新安装 `audio`/插件依赖（`pnpm install`）
4. 定时任务重写（见上表）
5. 跑一次面板「立即整理」验证路径

## 硬链接

原施工 Wiki 用硬链接省空间。硬链接在 Windows 上需要 NTFS 且同盘，
跨盘会失败 —— 现在的实现改成**复制**，跨平台更稳，代价是占空间。
