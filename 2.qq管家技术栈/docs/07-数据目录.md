# 07 数据目录

全部在 `~/.dsh-qqbot/`，与 DSH 自己的 `~/.dsh/` 分开。

```
~/.dsh-qqbot/
├─ archive/                 原始归档，按天一个 jsonl（入站 + 出站）
│   2026-11-13.jsonl
├─ archive2/
│   ├─ state.json           整理游标 + 群登记（openid → 名字/文件夹/条数）
│   └─ config.json          归档根目录、自动整理间隔、桥接机器人名单
├─ media/                   下载的图片/视频/文件，默认 24 小时清理
├─ modes.json               每个机器人的策略
├─ model-prefs.json         会话映射：qqbot:<botId>:<kind>:<peerId> → sessionId
├─ automations.json         定时任务数组
└─ workspace/               机器人默认工作目录
```

## state.json 结构

```json
{
  "cursors": { "2026-11-13.jsonl": 123456 },
  "groups": {
    "1905830497": {
      "64BC7DB6…": {
        "name": "施工测试 1",
        "folder": "施工测试 1",
        "createdAt": "2026-11-12",
        "botName": "小宝",
        "messages": 77
      }
    }
  }
}
```

`cursors` 是字节偏移，保证增量整理不重复。

## 备份建议

- `archive/` 是**唯一的原始数据**，其它都能重建
- `state.json` 丢了会重新扫一遍，但已登记的群名会丢
- `media/` 会过期，重要图片靠桥接复制到工程信息目录
