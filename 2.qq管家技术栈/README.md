# 2. QQ 管家技术栈

QQ 机器人 + 群聊归档 + 结构化工程资料的完整实现。

建立在 **DeepSeek Harness (DSH)** 之上，由两个自研插件组成，运行于 macOS 桌面端。

---

## 组成

| 插件 | 包名 | 作用 |
| --- | --- | --- |
| QQ 机器人 | `dsh-qqbot-multi` | 接入 QQ 官方机器人，收发消息、群聊归档、策略裁决、桥接生成 |
| QQ 管家 | `dsh-qq-butler` | Web 面板：归档目录、桥接开关、命令库、状态查看 |

数据全部落在 `~/.dsh-qqbot/`，与 DSH 自身的会话目录互不干扰。

## 能力一览

- 多个 QQ 官方机器人同时在线，各自独立选模型
- 每个机器人三种策略：静默收集 / 不收集 / 活跃
- 群聊全量归档（文字 + 图片 + 文件），含机器人自己的发言
- 归档按「机器人 / 群 / 日期」组织，同时生成可读的 txt
- 桥接生成施工 Wiki 式结构层：`年.月/日/聊天记录.md + events.jsonl + 图片/`
- 自动产出 `施工日志.xlsx` 与 `单价台账.xlsx`
- 群内命令：`/todo`（定时任务）、`/day`（当日总结）、`/rename`（群目录改名）、`/groups`
- 面板一键更新：从本仓库拉取最新插件代码

## 快速开始

1. 安装插件（见 `docs/09-更新机制.md`）
2. 面板 → 设置 → QQ 管家
3. 填归档目录 → 勾选桥接机器人 → 群里发 `/rename 项目名`

## 更新

两种方式，效果相同：

- **面板**：QQ 管家 →「检查更新」按钮
- **群里或私聊**：发 `/update`

更新内容是 `plugins/` 下的两个插件源码，拉取后覆盖到本机对应位置，重启桌面端生效。
